## 🐶 Chihuahua vs Muffin — Data-Centric AI with 3LC

> Can you tell a chihuahua from a muffin? We built an image classifier 
> using data-centric AI techniques with 3LC for the 3LC HACK[AI]THON.

## 🏆 Competition Results
- **Public Leaderboard Accuracy:** 92.4%
- **Model:** ResNet-18 (trained from scratch)
- **Platform:** 3LC Data-Centric AI

---

## 📌 Overview
This project was built for the 
[3LC HACK[AI]THON](https://www.kaggle.com/competitions/the-3lc-hackathon) 
Kaggle competition. The goal was to improve model accuracy not by 
changing the model architecture, but by improving the **data** using 
3LC's data-centric AI platform.

### What is Data-Centric AI?
> "Data-centric AI is the discipline of systematically engineering 
> the data used to build AI systems." — Andrew Ng

Instead of tuning the model, we focused on:
- Strategic labeling of unlabeled samples
- Removing noisy/ambiguous samples
- Using embeddings to find and fix mislabeled data
